## 5. Recommendation: Which 2 Findings to Add

1. **First choice — `effusion` (Pleural Effusion):**
   - **Strongest overall Reader signal:** Highest validation AUPRC (**0.391**, 95% CI `[0.361, 0.422]`) and second-highest AUROC (**0.832**, 95% CI `[0.818, 0.845]`) on NIH, and the **strongest zero-NIH-overlap CheXpert baseline** (`AUROC 0.774`, `AUPRC 0.241`), giving a strong starting point for `train`-only fine-tuning.
   - **Abundant data & boxes:** `6,964` train / `1,695` val / `4,658` test positives and `153` test bounding boxes.
   - **Pipeline compatibility:** Fits VeriRay's existing lung-mask shortcut gate (`localization_gate` = 3/100, `shortcut` = 19/100) and already achieves `2/100` `MODEL-SUPPORTED` without any threshold re-tuning.

2. **Second choice — `cardiomegaly` (or `atelectasis` if keeping the lung-mask shortcut rule strictly unchanged):**
   - **`cardiomegaly`** achieves the highest validation AUROC (**0.888**, 95% CI `[0.869, 0.906]`), `AUPRC 0.210`, the highest Judge acceptance rate (**3/100** `MODEL-SUPPORTED`), the lowest `controls_invalid` rate (**6/100**), and `146` test bounding boxes. **Required adaptation:** because the heart lies in the mediastinum *between* the segmented lungs, `cardiomegaly` triggers `21/100` `SHORTCUT_OUT_OF_LUNG_ATTRIBUTION` and `15/100` `JUDGE_FILL_METHOD_INSTABILITY`; extending VeriRay cleanly to `cardiomegaly` will require a mediastinal/cardiac ROI in the shortcut check rather than strict lung-parenchyma inclusion.
   - If zero changes to the lung-mask shortcut geometry are desired, **`atelectasis`** (`6,745` train / `1,535` val / `180` test boxes; `AUROC 0.754`, `AUPRC 0.224`; CheXpert `0.706` / `0.158`) is the best parenchymal alternative, though it requires managing `controls_invalid` (25/100) and `unrelated_label_drift` (21/100) due to frequent co-occurrence with effusion.
